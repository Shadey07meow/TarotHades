# Memoriam: Aspect of Fate
**Memoriam: Aspect of Fate** is a Java-based top-down dungeon crawler game developed using object-oriented programming principles and a custom engine structure. The project was designed as a strategy-focused action game.

## Installation & Execution Instructions
Here are the different ways you are able to compile game
- ### CLI (Command Line Interface)
To compile and run the game from your terminal:
    - 

Run the following command to compile the Java source files into the binary directory:


javac -d Memoriam/bin -sourcepath Memoriam/src Memoriam/src/MainGameDriver.java & java -cp Memoriam/bin MainGameDriver
